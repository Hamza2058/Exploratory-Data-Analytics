# 🏅 Olympics Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs an **Exploratory Data Analysis (EDA)** on an Olympics dataset to uncover patterns in athlete demographics, participation, and medal distribution across countries, genders, sports, and cities.

The goal of this project is to practice **real-world data analysis**, data cleaning, visualization, and insight generation using Python.

## 🧰 Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- NumPy

---

## 🔍 Key Analysis Performed
- Gender distribution of Olympic athletes  
- Medal distribution by gender and teams  
- Age distribution of athletes  
- Relationship between age and height  
- Athlete participation by sport  
- Athlete distribution by city and country (NOC)

---

## 📊 Visualizations Included
- Bar charts for gender and medal distribution  
- KDE plot for athlete age  
- Scatter plot for age vs height  
- Line plots for sports, cities, and countries  

(All plots are generated in the Jupyter Notebook.)

---

## 💡 Key Insights
- Olympic participation is uneven across genders and countries.
- Athlete ages cluster in early to mid-20s.
- A few sports and countries dominate participation and medals.
- Height variation is sport-driven rather than age-driven.

# Exploratory-Data-Analytics
📌 Project Overview

This repository contains two Exploratory Data Analysis (EDA) projects focused on real-world business datasets. The aim of these projects is to uncover meaningful patterns, customer behavior insights, and trends using Python-based data analysis and visualization techniques.

The projects emphasize data cleaning, structured analysis, and business-oriented interpretation, simulating real industry workflows.

🎯 Objectives

Perform data cleaning and preprocessing on raw datasets

Explore patterns and trends using visual analytics

Derive actionable business insights

Practice industry-standard EDA workflows

Build portfolio-ready analysis projects

📚 Dataset Descriptions
1️⃣ Books Dataset

The books dataset includes information such as:

Book names and authors

Publishing year

Genre

Language codes

Sales and ratings data

This dataset is used to analyze:

Publishing trends over time

Genre popularity

Author performance

Sales patterns

2️⃣ Shopping Trends Dataset

The shopping dataset contains customer and transaction details including:

Purchase amounts

Review ratings

Shipping types

Payment methods

Subscription status

Customer age and gender

Product categories

This dataset is used to understand:

Customer purchasing behavior

Product and category demand

Payment and shipping preferences

Demographic trends

🛠️ Tools & Technologies

Python

Pandas – data manipulation and cleaning

Matplotlib – data visualization

Seaborn – advanced statistical plots

NumPy – numerical operations

Google Colab / Jupyter Notebook

🔍 Key Analysis Performed
📘 Books Dataset

Distribution of publishing years

Genre frequency analysis

Book ratings comparison by genre

Relationship between price and units sold

Author-wise total sales analysis

🛒 Shopping Trends Dataset

Purchase amount vs review rating analysis

Shipping type and payment method usage

Gender and age distribution of customers

Category-wise purchase behavior

Subscription vs non-subscription trends

📈 Key Insights

Recent publications dominate the books dataset

Certain genres and authors generate significantly higher engagement

Lower-priced products generally sell more units

Positive reviews are associated with higher spending

A small number of payment and shipping methods dominate usage

Most purchases are made by specific demographic age groups

## 📚 Project Descriptions

### 📘 Books Dataset EDA
This project explores trends in book publishing and sales, including:
- Publishing year distribution
- Genre frequency and popularity
- Book ratings analysis
- Relationship between price and units sold
- Author-wise sales performance

**Key Focus:** Market trends, reader preferences, and content demand.

---

### 🛒 Shopping Trends EDA
This project analyzes customer purchasing behavior using transactional data, including:
- Purchase amount vs review ratings
- Shipping and payment method preferences
- Category-wise demand
- Subscription vs non-subscription behavior
- Customer age and gender distribution

**Key Focus:** Customer behavior, pricing patterns, and operational insights.

## ⚠️ Troubleshooting & Common Issues

- **Plots not displaying:**  
  Ensure `%matplotlib inline` is enabled if using Jupyter Notebook.

- **Missing files error:**  
  Verify that CSV files are located in the `data/` directory and paths are correct.

- **Data type issues:**  
  Some columns require type conversion (handled within notebooks).  
  Re-run data cleaning cells if errors occur.

- **Seaborn errors:**  
  Make sure Seaborn is installed and imported correctly.
